# M3U8播放器产品需求文档

## 1. 项目概述

### 项目名称
M3U8在线播放器

### 项目类型
移动端H5视频播放应用

### 核心功能
一款现代化、扁平化与新拟态(Neumorphism)风格融合的手机版M3U8在线播放器,支持HLS流媒体播放。

### 目标用户
- 移动端用户(主要iPhone和Android手机)
- 需要播放M3U8格式流媒体的用户
- 追求美观、现代化UI的用户

## 2. 技术栈要求

### 前端框架
- React 18
- TypeScript
- Vite(构建工具)

### 样式方案
- Tailwind CSS
- 自定义CSS实现新拟态效果

### 核心库
- HLS.js - M3U8流解析
- React Router DOM - 页面路由

### 架构要求
- 函数式组件 + Hooks
- 组件化开发
- 移动端优先设计(375-428px宽度)

## 3. 页面结构与路由

### 路由配置
```
/           - 首页(M3U8链接输入页)
/player     - 播放页(接收URL参数中的m3u8链接)
```

### 页面说明
1. **首页(/)**: M3U8链接输入页面
2. **播放页(/player)**: 独立的视频播放页面,通过路由参数传递m3u8链接

## 4. 首页详细设计

### 整体风格
- **设计风格**: 新拟态(Neumorphism)
- **背景色**: #e8ecf1(浅灰色)
- **卡片凸起阴影**: `5px 5px 15px #c4c9d0, -5px -5px 15px #ffffff`
- **卡片凹陷阴影**: `inset 3px 3px 8px #c4c9d0, inset -3px -3px 8px #ffffff`

### 顶部标题区
- 展示"M3U8播放器"文字
- 使用扁平化现代字体
- 微妙的字间距
- 颜色:主色调蓝紫色#7c6ff7

### 中央输入区
- **新拟态输入框**: 凹陷效果
- **Placeholder**: "请输入M3U8播放链接"
- **圆角**: 16px
- **带柔和内阴影**: inset shadow

### 播放按钮
- **位置**: 输入框下方
- **效果**: 凸起效果的新拟态按钮
- **按压动画**: 按压时凹陷的动画反馈
- **颜色**: 柔和的蓝紫色渐变(#7c6ff7 → #6c63ff)
- **过渡动画**: 200-300ms

### 历史记录区域
- **位置**: 底部
- **展示方式**: 凸起卡片展示最近播放的链接
- **存储**: localStorage
- **交互**: 点击可快速播放

## 5. 播放页详细设计

### 页面布局
- 独立页面,通过路由跳转进入
- 接收URL参数中的m3u8链接

### 返回按钮
- **位置**: 顶部左侧
- **样式**: 新拟态凸起圆形按钮
- **交互**: 点击返回首页

### 播放器区域
- **布局**: 占屏幕上半部分
- **背景**: 黑色
- **高度**: 约40vh(竖屏)
- **适配**: playsinline和webkit-playsinline属性

### 播放信息区
- **样式**: 新拟态凸起卡片
- **内容**:
  - 当前播放链接(截断显示)
  - 播放状态(加载中/播放中/错误等)

### 控制栏
- **设计**: 扁平化半透明设计
- **位置**: 覆盖在视频底部
- **功能**:
  - 播放/暂停按钮
  - 进度条(新拟态凹槽+凸起滑块)
  - 当前时间/总时长显示
- **图标**: 简洁的SVG线条图标(不使用emoji)

## 6. 横竖屏与全屏适配

### 竖屏模式(默认)
- 播放器宽度100%
- 高度约40vh
- 视频信息在下方显示

### 横屏/全屏模式
- 播放器全屏展示
- 控制栏自动适配
- 信息区隐藏

### 技术实现
- 使用CSS媒体查询`orientation`或`matchMedia`监听横竖屏切换
- 使用Fullscreen API实现全屏
- 退出全屏时恢复竖屏布局
- 兼容iPhone Safari和安卓Chrome(playsinline属性)

## 7. HLS播放实现

### HLS.js集成
- 使用hls.js库加载M3U8链接
- 检测浏览器是否原生支持HLS(Safari),是则直接用video标签src
- 否则使用hls.js加载

### 异常状态处理
- 加载中状态提示
- 播放错误提示
- 链接无效提示
- 使用新拟态风格的提示卡片展示

### 自动播放策略
- 用户点击播放按钮后开始加载
- 避免自动播放被浏览器拦截
- 显示加载进度指示

## 8. 组件拆分

### 组件文件列表
1. **NeumorphicInput.tsx** - 新拟态输入框组件
2. **NeumorphicButton.tsx** - 新拟态按钮组件(支持按压动画)
3. **NeumorphicCard.tsx** - 新拟态卡片容器
4. **HomePage.tsx** - 首页
5. **PlayerPage.tsx** - 播放页
6. **VideoPlayer.tsx** - 视频播放器核心组件(含HLS逻辑)
7. **PlaybackControls.tsx** - 播放控制栏
8. **HistoryList.tsx** - 历史记录列表
9. **App.tsx** - 主应用路由配置

## 9. 设计细节补充

### 颜色系统
- **背景色**: #e8ecf1
- **主色调**: #7c6ff7(蓝紫色)
- **次要色**: #6c63ff(深蓝紫色)

  - `inset 3px 3px 8px #c4c9d0`
  - `inset -3px -3px 8px #ffffff`

### 圆角规范
- 统一使用12-16px

### 字体
- 系统默认无衬线字体

### 触控规范
- 所有可点击区域最小44x44px

### 动画规范
- 所有交互都有细腻的过渡动画
- 过渡时长: 200-300ms

### 页面可见性处理
- 切换tab时暂停播放
- 页面不可见时暂停
